# k-Edufine Desktop Counter Monitor

이 프로젝트는 GPKI 인증서로 로그인해야 하는 k에듀파인 업무 포털에서 결재·공람·문서진행·발송대기·메모·메일 등의 카운트가 변경될 때 사용자에게 알려주는 데스크톱 에이전트입니다. 내장 브라우저에서 직접 로그인한 뒤, 프로그램이 주기적으로 화면을 읽어 카운트 변화를 감지합니다.

> ⚠️ 실제 페이지 구조는 기관·버전에 따라 다릅니다. **반드시 `desktop_agent/config/selectors.json` 파일에서 각 항목의 CSS 선택자를 확인하고 수정**한 뒤 사용하세요.

---

## 1. 사전 준비 (Windows 10/11 기준)

1. **Python 설치**
   - [Python 공식 다운로드 페이지](https://www.python.org/downloads/windows/)에서 `Windows installer (64-bit)`를 내려받아 설치합니다.
   - 설치 화면에서 **"Add Python to PATH" 옵션을 반드시 체크**하고 `Install Now`를 누릅니다.

2. **설치 확인**
   - 시작 메뉴에서 "PowerShell" 또는 "명령 프롬프트"를 열고 아래 명령을 입력합니다.

     ```powershell
     python --version
     ```

   - `Python 3.x.x` 형태의 버전이 표시되면 준비가 완료된 것입니다. 오류가 난다면 Python을 다시 설치하면서 PATH 옵션이 선택되었는지 확인합니다.

3. **필요한 파일 위치 확인**
   - 이 저장소 전체를 PC의 원하는 폴더(예: `C:\k-edu-agent`)에 다운로드합니다. 방법은 아래 2장에서 설명합니다.

---

## 2. 소스 코드 받기

1. **Git을 사용할 수 있는 경우**

   ```powershell
   cd C:\
   git clone https://github.com/naratmal/naratmal.github.io.git
   cd naratmal.github.io
   ```

2. **Git이 없는 경우 (ZIP 다운로드)**
   1. 웹 브라우저에서 GitHub 저장소 페이지를 열고 `Code` > `Download ZIP`을 클릭합니다.
   2. 압축 파일을 원하는 폴더(예: `C:\k-edu-agent`)에 압축 해제합니다.
   3. 압축 해제 후 `desktop_agent` 폴더가 있는지 확인합니다.

이제 `naratmal.github.io` 폴더(또는 ZIP을 풀어 만든 폴더)를 기준으로 이후 단계를 진행합니다.

---

## 3. 가상환경 만들기

프로그램에 필요한 라이브러리를 다른 프로젝트와 분리해서 관리하기 위해 **가상환경**을 사용합니다.

1. PowerShell 또는 명령 프롬프트에서 프로젝트 폴더로 이동합니다.

   ```powershell
   cd C:\k-edu-agent\naratmal.github.io
   ```

2. 아래 명령으로 가상환경을 만듭니다.

   ```powershell
   python -m venv .venv
   ```

3. 가상환경을 활성화합니다.
   - PowerShell: `.\.venv\Scripts\Activate.ps1`
   - 명령 프롬프트: `.\.venv\Scripts\activate`

   활성화되면 프롬프트 앞에 `(.venv)`가 붙습니다. 이 상태에서만 다음 단계들을 실행하세요.

---

## 4. 필요한 패키지 설치

가상환경이 활성화된 창에서 다음 명령을 입력합니다.

```powershell
pip install -r desktop_agent\requirements.txt
```

설치가 끝날 때까지 기다립니다. 설치 도중 "Build Tools" 관련 오류가 나면, [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)를 설치한 뒤 다시 시도하세요.

---

## 5. 카운트 선택자 설정

프로그램이 k에듀파인 화면에서 카운트를 찾을 수 있도록 **CSS 선택자**를 지정해야 합니다.

1. `desktop_agent\config\selectors.json` 파일을 메모장이나 VS Code로 엽니다.
2. 각 항목에 실제 페이지에서 사용하는 선택자를 입력합니다. 예시는 다음과 같습니다.

   ```json
   {
     "결재": "#approvalCount",
     "공람": "#inspectionCount"
   }
   ```

3. 선택자를 찾는 방법
   - **프로그램 내 `선택자 추출` 버튼 사용 (권장)**:
     1. `python desktop_agent\main.py`로 프로그램을 실행한 뒤, 내장 브라우저에서 k에듀파인에 로그인합니다.
     2. 하단의 `선택자 추출` 버튼을 누르면 화면 전체에 붉은 테두리가 나타나며 "교차선" 커서로 바뀝니다.
     3. 모니터링하고 싶은 카운트 숫자를 마우스로 클릭하면 해당 요소의 CSS 선택자가 자동으로 계산되어 **클립보드에 복사**되고, 하단 상태줄과 로그에 표시됩니다.
     4. `selectors.json`에 복사된 선택자를 붙여넣고 저장합니다.
     5. 취소하려면 `선택자 추출` 버튼을 다시 누르거나 키보드 `Esc`를 누르세요.
   - **(선택) 크롬 개발자 도구 사용**: 기관 보안 모듈(WebDRM 등)에서 개발자 도구를 차단하지 않는 환경이라면, 기존 설명대로 `F12` → 요소 선택 → `Copy selector` 흐름을 사용할 수 있습니다. 단, 차단 경고가 뜨면 위의 내장 추출 도구를 이용하세요.
   - 선택한 요소가 iframe 내부에 있다면 추출된 경로에 iframe 관련 정보가 포함될 수 있습니다. 이 경우 `selectors.json`에서 iframe 안쪽 구조에 맞게 조정해야 합니다.

선택자가 잘못되면 프로그램이 숫자를 읽지 못하므로, 반드시 실제 페이지 구조에 맞게 수정해주세요.

---

## 6. 프로그램 실행

1. 가상환경이 활성화된 PowerShell/명령 프롬프트 창에서 아래 명령을 입력합니다.

   ```powershell
   python desktop_agent\main.py
   ```

2. 프로그램 창이 열리면 기본 페이지로 k에듀파인 로그인 화면이 나타납니다.
3. **사용자가 직접** GPKI 인증서를 선택하고 비밀번호를 입력해 로그인합니다.
4. 로그인에 성공하면 상단에 k에듀파인 메인 화면이 표시되고, 하단 로그 영역에 "모니터링 시작" 메시지가 나타납니다.
5. 이후 기본값으로 **1분마다** 카운트가 갱신되며, 이전 값과 달라지면 로그와 시스템 알림으로 결과가 표시됩니다.

> 알림을 받으려면 `plyer` 패키지가 정상 설치되어 있어야 하며, Windows 알림이 꺼져 있지 않은지 확인하세요.

---

## 7. 로그와 알림 활용 방법

- **하단 로그 패널**: 실시간으로 변경 이력이 쌓이며, `로그 저장` 버튼을 눌러 텍스트 파일로 내보낼 수 있습니다.
- `선택자 추출` 기능을 사용하면 어떤 선택자를 복사했는지 `[선택자 추출] ...` 형식으로 로그에도 함께 기록됩니다.
- **시스템 알림**: 숫자가 바뀌는 즉시 윈도우 알림 센터에 팝업이 표시됩니다. 알림이 보이지 않으면 `설정 > 시스템 > 알림`에서 Python 또는 해당 앱의 알림이 허용되어 있는지 확인하세요.

## 8. 자주 발생하는 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| `python` 명령이 인식되지 않습니다 | Python을 다시 설치하면서 "Add Python to PATH" 옵션을 켰는지 확인하고, 새 PowerShell 창을 열어 다시 시도합니다. |
| `pip install` 도중 오류 발생 | 인터넷 연결을 확인하고, 관리자 권한 PowerShell에서 실행해 보거나 C++ Build Tools를 설치합니다. |
| 프로그램은 실행되지만 카운트가 0으로만 나옵니다 | `selectors.json`에 입력한 선택자가 실제 요소와 다르거나 iframe 내부에 있을 수 있습니다. 개발자 도구에서 정확한 선택자를 다시 확인합니다. |
| `선택자 추출` 버튼을 눌렀는데 아무 숫자도 선택되지 않습니다 | 로그인 후 해당 화면이 완전히 로드되었는지 확인하고, 팝업 차단 프로그램이 있다면 일시 중지한 뒤 다시 시도합니다. 필요한 경우 `Esc`로 취소한 뒤 버튼을 다시 누르세요. |
| 알림이 보이지 않습니다 | Windows 알림 설정에서 "알림"이 켜져 있는지 확인하고, 알림이 집중 지원에 의해 숨겨지지 않았는지 확인합니다. |
| 세션이 자주 끊깁니다 | k에듀파인 정책에 따라 일정 시간마다 재로그인이 필요할 수 있습니다. 새로 고침 버튼을 누르거나 프로그램을 다시 실행해 세션을 갱신합니다. |

---

## 9. 추가 설정 (선택)

- **조회 주기 변경**: `desktop_agent\main.py`에서 `CHECK_INTERVAL_MS = 60 * 1000` 값을 원하는 밀리초 단위로 바꿉니다. 예를 들어 30초 간격이면 `30 * 1000`으로 수정합니다.
- **알림 끄기**: 알림이 필요 없다면 `plyer` 설치를 생략하거나 `main.py`의 `append_change` 메서드에서 알림 관련 코드를 주석 처리합니다.
- **다른 PC에서 사용**: 위 단계를 다른 PC에서도 동일하게 반복하면 됩니다. 단, `selectors.json`은 환경마다 다시 확인해야 합니다.

---

## 10. 참고 사항

- 프로그램은 GPki 인증서를 자동으로 조작하지 않으며, **로그인 과정은 반드시 사용자가 직접** 진행해야 합니다.
- k에듀파인 화면 구조가 바뀌면 `selectors.json`을 다시 수정해야 합니다.
- 기관의 보안 정책상 자동화 도구 사용이 제한될 수 있으므로, 필요한 경우 정보보안 담당 부서의 승인을 받는 것이 좋습니다.
